# 真实行情与快照实施计划

用户已通过逐项访谈确认以下范围，并授权实施。

## 已确认口径

- 首页展示四项指数最新可用行情，行情时间与采集时间分别保存。
- 打开页面只读取已有快照；手动刷新启动新采集，不自动定时采集。
- 各模块独立发布完整快照，失败保留旧快照并显示原因；股票整批切换。
- 沪深 A 股默认全部展示，成交额门槛默认为零。
- 昨日全天成交额和今日累计成交额分别展示，默认按昨日成交额筛选和降序排列。
- 行业和概念分别显示，允许多归属，详情显示完整归属。
- 历史快照仅保存，首版不提供历史浏览；不覆盖或重算正式盘前报告。
- 缺失为 null，交易状态标记未核验，不以演示值填充。

## 实现与验收

1. 先写客户端、采集器、快照存储失败测试；实现协议校验、时间口径、完整分页及原始响应留存。
2. 实现本地 FastAPI 服务及手动后台采集；测试失败保留、并发刷新、防伪及访问边界。
3. 基于既有原型视觉实现正式轻量页面，使用原生 JavaScript 同源请求。
   本次无需完整迁移旧工作台 Vue 方案，也不接入尚未实现的报告发布和风险分析界面。
4. 执行全部 Python 测试和静态检查、前端筛选排序测试及浏览器交互验收。
5. 用真实接口验证采集与持久化，记录实际覆盖与限制，更新启动和恢复文档。

## 技术约束

- 新代码中文注释及错误、英文小驼峰标识符、两空格缩进，UTF-8 无 BOM、LF。
- 凭据只在服务端环境读取；快照存于 outputs/market，浏览器不能直接下载原始文件。
- 快照历史使用唯一标识，不可覆盖；最新指针原子切换，失败不能损坏原版本。
- 首次全市场日 K 采集可能较慢，后台执行；已有完整历史日成交额可以缓存。
- 当前板块成分仅表示采集时点，不倒填历史归属；快照时间不能冒充盘前已知数据。
