# 首板命中与下行风险冲突：第一步诊断结果

日期：2026-10-03。状态：已完成全部 50 个目标组合的股票、日期、环境和评分依据诊断。

**结论：风险超标主要表现为普遍的选股偏向，少数异常日期或个别股票不足以解释。
下一步更值得优先研究风险评分依据，再做有限权重细化。此次没有修改评分、搜索新权重或启用正式推荐。**

## 一、分析对象及可信边界

筛选第三版中训练、验证两段已记录封板比例均不低于同环境等权基准的全部 50 个非等权组合。
它们来自 17 种权重：ALL 17 组、ABC 17 组、AB 16 组；其中 42 组下行稳定性权重为零，8 组为 25%。
这些组合的样本量、封板事件数及分布均已达标，但两段平均下行都超标。

只使用既有开发训练 2025-09-17 至 2026-03-16、开发验证 2026-03-17 至 06-16。
没有读取旧留出或未来标签，没有补下载或重建面板。诊断按既有权重还原名单，未重新选择权重。

共还原 7,699 个“组合—日期”配对、139,174 条证券贡献项。
组合高度重叠，去重后只有 9,283 个候选股票日、9,654 个候选与基准并集股票日，
不能把组合重复记录当作独立样本或由此宣称统计显著。

这里的下行是相对当天开盘至最低点的跌幅；差值单位为百分点，不是账户回撤或可成交损益。
训练仍有少量缺行情，分别按两侧有效股票数归因；未填零。

## 二、风险超标并未集中于少数异常日或个别股票

下表是 50 个组合各自统计的分布，不是合并股票日得到的总体指标。

| 指标 | 训练期 | 验证期 |
| --- | ---: | ---: |
| 平均下行高于基准的幅度范围 | +0.222～1.574 个百分点 | +0.185～1.359 个百分点 |
| 风险高于基准的日期占比范围 | 62.8%～92.2% | 62.8%～90.7% |
| 上述日期占比的组合中位数 | 80.1% | 79.7% |
| 删除各自最大五个正差日期后仍超标 | 50 / 50 | 50 / 50 |
| 删除后平均风险差范围 | +0.157～1.437 个百分点 | +0.029～1.074 个百分点 |
| 前五个日期占全部正日期贡献 | 12.2%～29.7% | 23.9%～53.9% |
| 前五只股票占全部正证券贡献 | 4.4%～13.4% | 7.0%～22.7% |

前五日确实解释一部分风险，但移除后仍普遍超标。前五股的集中度也不足以解释全部问题。
这只是事后敏感性分析；不能把这些日期或股票加入黑名单后，宣称得到了可盘前执行的新策略。
集中度分母为所有正贡献之和，不是被负贡献抵消后的净差。

## 三、环境分解：问题不限于最差环境

按每个组合与基准在相同环境日期的平均下行差比较：

| 环境等级 | 训练超标组合 / 包含该环境的组合 | 验证超标组合 / 包含该环境的组合 | 训练 / 验证观察日 |
| --- | ---: | ---: | ---: |
| A | 50 / 50 | 47 / 50 | 22 / 14 |
| B | 50 / 50 | 50 / 50 | 56 / 29 |
| C | 34 / 34 | 34 / 34 | 25 / 18 |
| D | 16 / 17 | 17 / 17 | 10 / 1 |

B 环境的所有 50 组在两段都超标；C 环境的 34 组也全部超标。
所以仅排除 D 环境不能解决本轮问题。D 的验证仅一天，不足以形成稳定结论。
A 的部分验证改善也不能用于事后临时增加 A-only 规则。

## 五、评分依据暴露出的倾向

与同日等权名单相比，50 组中：

- 五日涨幅更高：训练 50 组，验证 47 组。
- 历史收盘下行 RMS 更高：训练 45 组，验证 48 组。

代表案例训练的平均五日涨幅为 11.739%，基准为 10.190%；验证为 12.943% 对 11.780%。
案例的历史下行 RMS 也更高，过去五日收盘在各日高低区间中的平均位置反而更低。
这些证据表明名单更偏向近期上涨较强、同时带有更多历史下行波动的股票；尚不能称为因果解释。

现有风险评分使用“过去 20 日收盘负收益的均方根”，目标考核却是“观察当天开盘至最低点的跌幅”。
两者衡量的时间段和价格路径不同。仅把前者权重调大或调小，不保证能控制后者。
这是来自实现定义的明确口径差异，但不是已证明新特征一定有效。

案例按事件组分解也不能简单归咎于炸板：

| 事件组 | 训练平均风险差贡献 | 验证平均风险差贡献 |
| --- | ---: | ---: |
| 未记录事件、标签未知 | +0.22885 | +0.24240 |
| 已记录封板 | -0.00056 | +0.01231 |
| 已记录触板未封 | +0.01011 | -0.00233 |

主要增量在未记录事件组，但它本来就包含绝大多数观察股票。
不能将其写成“确定没涨停”或“错误推荐”，也不能把结果事件用作当日盘前过滤信息。

## 六、下一步方向

优先做一个有限、预先固定的新研究版本，检验与考核更一致的盘前风险依据，例如：

1. 过去若干日开盘至最低点的下行幅度及其尾部，仅使用观察日前已经结束的日线。
2. 在同一风险约束下检验近期涨幅较强时的风险差异，避免把更强趋势一律视作更好。
3. 风险依据明确后，再将更细权重网格作为有限对照；继续保留命中与实际风险门槛。

本轮没有证明更细权重必然无效，也没有证明新风险特征有效。
建议的优先顺序来自跨日期、股票及环境均存在的超额风险，而非保证下一次优化成功。
下一版仍需新样本外验证；本轮只完成用户要求的失败原因分析，不自动实施上述变更。
