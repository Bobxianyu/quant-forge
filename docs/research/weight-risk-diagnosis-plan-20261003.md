# 权重命中与风险冲突诊断口径

日期：2026-10-03。用户要求先完成失败原因分析。本轮不搜索新权重，不修改推荐规则。

## 固定对象和数据边界

使用第三版冻结结果，筛出训练、验证两段已记录封板比例都不低于同环境等权基准的非等权组合。
预期 50 个组合，全部纳入诊断，不只挑表现好的例子。旧结果摘要、协议及实现先核验。
只加载原训练和验证面板，2026-06-17 起旧留出及未来标签不参与分析。
不下载历史数据、不重构面板、不调用新的权重搜索。

## 配对归因

- 每个组合按原评分还原每日名单，与相同日期、环境、每日数量的等权名单比较。
- 训练、验证分别报告；环境 A/B/C/D、月份、日期和证券代码分别汇总。
- 每日下行差 = 候选名单有效结果的平均下行 - 基准名单有效结果的平均下行。
- 每个证券当天的贡献 = 候选中该股下行 / 候选有效数 - 基准中该股下行 / 基准有效数。
  一侧未选择或无有效结果时没有该侧贡献项；保留缺失计数，不把缺失股认定为零风险。
  两侧都无有效均值或任一侧无有效均值时，该日不作配对归因，单独记录。
- 证券贡献的总和必须还原每日下行差；日期均值必须还原冻结结果的平均下行差。
- 相同证券在多个组合被选中不当作新的独立样本；跨组合仅报告分布、范围及覆盖个数，不合并成总体命中率。

## 集中度和评分依据

- 报告风险较高日期占比、贡献最大的前五日、前五股及其占全部正贡献的比例。
  正贡献比例的分母不是净差，避免负贡献抵消后出现误导性比例。
- 事后剔除最大五个正差日期的双边配对敏感性仅用于判断是否集中于少数日，不能据此制定盘前过滤规则。
- 分别报告已记录封板、已记录触板未封、未记录事件三类的贡献和数量；未记录事件保持未知。
- 比较入选及基准的四项盘前原始特征和排名百分位，说明更换权重实际偏向何种股票。
- 尾部风险按两边各自最差 10% 日期计算，说明尾部日期集合不一定相同，不冒称可直接相减分摊。
- 选取平均风险超额的两段最大值最小的组合做明确标注的“最接近风险门槛”案例，仅用于诊断。
