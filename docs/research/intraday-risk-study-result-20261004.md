# 盘中风险评分替代研究结果

完成日期：2026-10-04。协议及目录保留启动日期 2026-10-03。

**本轮已完成：两个新风险指标都降低了相同权重下的历史下行幅度，但验证期封板命中同步减少。
固定 210 个配置没有一个同时通过全部命中和风险门槛，没有选出新开发候选。**

## 一、这次具体检验了什么

在原候选和原四项权重结构不变的条件下，分别替换风险项：

- 历史盘中下行均值：此前 20 个参考交易日的 `(开盘 - 最低) / 开盘` 均值。
- 历史盘中下行尾部：同一窗口中最差两日的平均下行。

两者均使用 D 及以前的日线，不读取观察日 T 的价格或标签作为评分输入。
原风险项为过去 20 日收盘负收益的均方根；五日趋势、收盘位置、流动性继续保持原样。

每个新风险版本比较 35 组权重、3 种环境，共 105 个配置。
两版合计 210 条配置记录，其中风险权重为零的 90 条记录引用同一批旧 45 组结果，
真正新计算的是 120 个配置。不能将重复引用当成独立证据。

本轮始终使用原第三版的等权评分名单作为门槛基准。
新风险版本的四项各 25% 是新候选，不是自动达标的基准；另存每组与旧相同权重的比较。
协议见 [冻结实施计划](intraday-risk-study-plan-20261003.md)。

## 三、主要结果：风险改善与命中损失同时出现

以下只统计每版 60 个风险权重大于零的新计算配置，不重复计算 45 组旧零风险对照。
“风险达标”指训练、验证的平均与尾部下行均不高于原等权基准。
“命中达标”指两段已记录封板比例均不低于原等权基准；样本量等其他要求另行检查。

| 检查 | 盘中均值版 / 60 | 盘中尾部版 / 60 |
| --- | ---: | ---: |
| 两段风险均达标 | 54 | 55 |
| 两段命中均达标 | 2 | 0 |
| 两段风险和命中同时达标 | 0 | 0 |
| 全部门槛通过 | 0 | 0 |
| 相同旧权重下，两段平均下行都降低 | 60 | 60 |
| 相同旧权重下，验证尾部下行降低 | 60 | 60 |
| 相同旧权重下，验证封板事件减少 | 60 | 60 |

这是实质性的取舍：更贴近目标的风险项降低了本次样本的下行幅度，但也减少了首板正事件。
不能据此把新风险项称为无效，也不能仅凭风险下降就通过验收。
由于没有组合同时满足相对风险和相对命中要求，本轮失败不是仅由“至少十次封板”等样本门槛造成。

## 四、固定等权对照：风险下降了多少，命中损失了多少

为保持解释清楚，以下固定 ABC 环境、四项各 25%。原版是门槛基准，两行新版只是替换风险项。

| 训练，均为 1,030 条观察 | 原风险项 | 盘中均值项 | 盘中尾部项 |
| --- | ---: | ---: | ---: |
| 已记录封板数 | 29 | 20 | 16 |
| 平均下行 | 1.893% | 1.596% | 1.580% |
| 尾部下行 | 3.892% | 3.509% | 3.488% |
| 平均盘中上涨空间 | 2.391% | 1.966% | 1.879% |

| 验证，均为 610 条观察 | 原风险项 | 盘中均值项 | 盘中尾部项 |
| --- | ---: | ---: | ---: |
| 已记录封板数 | 22 | 7 | 8 |
| 已记录封板比例 | 3.607% | 1.148% | 1.311% |
| 平均下行 | 2.192% | 1.732% | 1.665% |
| 尾部下行 | 4.762% | 3.531% | 3.397% |
| 平均盘中上涨空间 | 2.544% | 1.840% | 1.796% |

因此，新等权方案虽然风险更低，但封板记录明显更少，不能替换原基准或正式推荐。

## 五、保住命中的两个配置为什么仍未通过

新增配置中，只有盘中均值版的 `25 / 75 / 0 / 0`，在 ALL 和 ABC 环境下两段命中达标。
权重顺序为新风险项、五日趋势、收盘位置、流动性。两者的尾部下行也达标，
但平均下行仍高于各自原等权基准。

| 环境 | 训练封板：方案 / 基准 | 验证封板：方案 / 基准 | 训练平均下行增量 | 验证平均下行增量 |
| --- | ---: | ---: | ---: | ---: |
| ALL | 33 / 31，同为 1,130 条 | 27 / 22，同为 620 条 | +0.211 个百分点 | +0.097 个百分点 |
| ABC | 32 / 29，同为 1,030 条 | 27 / 22，同为 610 条 | +0.207 个百分点 | +0.096 个百分点 |

例如 ABC 的验证尾部下行从基准 4.762% 降至 3.794%，但平均下行从 2.192% 升至 2.289%。
尾部改善不能抵消用户已确认的平均下行要求，因此没有为这两个组合降低门槛。
上述是全部命中达标的新配置，不是选出来上线的方案。

## 六、对上一轮诊断的回应

上轮建议优先使风险评分更贴近盘中下行目标。本轮结果支持它确实改变了名单的下行表现：
所有 120 个新配置在相同权重、相同环境下的两段平均下行都低于旧版本。
但验证期 120 个配置的封板记录也全部少于旧同权重版本，说明单独替换风险项仍无法完成全部目标。

这不等于更细权重没有解。本轮只覆盖 25% 步长的固定范围，没有连续权重最优性结论。
若继续，较有依据的下一步是围绕盘中均值版做预先限定的小范围权重比较，
观察风险与命中之间是否存在同时达标的区间；不能无上限扩展搜索或事后放松门槛。
本轮未执行该后续比较，也没有增加新特征、历史窗口或环境规则。

## 七、适用范围及未解决问题

- 训练和验证已反复用于研究，这些只是开发结果，没有新的样本外证明。
- 历史交易资格、合法涨停价、证券全集和池外标签仍存在既有缺口，未用当前状态回填。
- 封板比例为已记录事件比例，不是真实完整封板率；未记录事件仍是未知。
- 下行和上涨空间是相对开盘的盘中观察指标，没有成交假设，不是账户收益或最大回撤。
- 210 条配置高度相关，90 条是重复引用，不能当作独立试验数量做统计推断。
- 正式推荐未修改，没有开启新的自动采集或恢复暂停的每小时任务。
