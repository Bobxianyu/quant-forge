# 首次启动套利模式的指标选择

记录日期：2026-09-14。依据：用户本轮提供的最新模式说明。
状态：业务研究与数据候选清单，不代表已实现或已验证收益有效性。

## 1. 模式定位

模式为“大单净流入、小单净流出、买单大于卖单、分时回踩突破”的首次启动套利。
四项表现指标衡量前一批参与者的后续溢价，不能仅按普通大盘指数理解。

| 指标 | 主要职责 |
| --- | --- |
| 昨日打首板表现 | 核心环境：首板参与者有没有溢价，首次启动套利是否匹配市场 |
| 昨日涨停表现 | 总体环境：短线赚钱效应是否广泛存在 |
| 昨日非 ST 二板表现 | 风格：市场是否更奖励二进三接力 |
| 最近多板 | 风格和风险偏好：高位接力是否强势或退潮 |

二板、多板强不等于本模式应提高仓位；首板与总体表现冲突时必须提示分化。
首板强、二板和多板弱属于高低切候选，不自动等于最高权限，还要看总体溢价与亏损扩散。
用户给出的 +0.23%、+5.87%、+3.97%、+1.49% 是模式示例，不当作当前行情。

用户给出的 A/B/C/D 阈值与仓位是待检验规则；2～3 成究竟指单笔还是账户总仓位尚需明确。
现有系统区分账户总仓位和单笔仓位，本次不据此覆盖现有配置。
C 级示例与其他级别未覆盖所有组合，指标冲突、零值及数据缺失仍需单独规定。

## 2. 指标优先级

下列衍生指标是针对本模式的研究建议，非供应商已有同名字段。

| 优先级 | 指标 | 候选定义 | 用途 |
| --- | --- | --- | --- |
| P0 | 四项原始表现 | 官方序列及编制口径待确认 | 确立环境与风格，不猜代码 |
| P1 | 首板样本赚钱比例 | 前一交易日首板样本在观察时点收益为正的数量占比 | 判断均值是否由少数强股抬高 |
| P1 | 首板收益中位数与下尾收益 | 固定首板样本的收益中位数、低分位数 | 观察典型结果与亏损尾部 |
| P1 | 首板相对强弱 | 首板表现减二板表现、首板表现减多板表现，单位百分点 | 辅助区分低位套利与高位接力 |
| P1 | 首板封板成功比例 | 收盘封板的首次触板股票数除以当日首次触板股票数 | 衡量首板承接；先核实完整触板样本 |
| P1 | 断板亏损与跌停数量 | 固定此前连板样本，观察后续断板股收益分布 | 判断高位风险是否向低位扩散 |
| P1 | 目标板块首板贡献与广度 | 板块首板数、上涨占比及相对全市场收益 | 判断个股启动是否有板块支持 |
| P2 | 大单净流入强度 | 同时间窗口的大单净额除以成交额 | 将个股资金量按交易活跃度归一化 |
| P2 | 小单净流出强度 | 同窗口小单净额除以成交额 | 与大单方向组合观察，避免单独解释 |
| P2 | 主动买入金额占比 | 主动买入额除以主动买入额与主动卖出额之和 | 候选成交方向指标，待用户确认语义 |
| P2 | 回踩缩量比例 | 回踩段单位时间成交额除以首轮拉升段单位时间成交额 | 检验回踩时卖压是否收缩 |
| P2 | 突破确认与追高距离 | 突破已形成的局部高点、突破段成交及距失效位距离 | 明确触发与风险边界 |

P2 代表个股触发层，并非其对交易不重要；当前尚缺可验证的在线数据来源。
成交额为零、无法分类的成交、缺价和停牌均单独处理，不填成零收益或零买入。
自算样本指标必须记录样本数、有效覆盖率、ST/新股过滤、收益起点、权重与复权口径。
不能假定自算平均收益与同花顺四项指数完全等价。

## 3. 时间边界

08:50 报告只能采用此前完整形成的数据，得到的是前一交易日环境基线。
“昨天首板的人今天有没有赚钱”必须在今天已有可用行情后判断，不能在 08:50 提前得到。
后续若加入盘中判断，应保存独立的观察时点快照，不回写盘前报告。

盘中比较必须对齐时点；例如开盘不久的首板表现不能直接和另一日收盘表现混合统计。
回踩与突破算法只能使用触发时已出现的数据，不能用整日最高价或事后识别的完整波段做信号。
全日炸板比例、断板结果等收盘后才确定的指标，只能用于下一交易日基线或事后评价。

## 4. 数据可得性

- [行情与历史日 K](https://fuyao.aicubes.cn/docs/api-reference/prices/)：可作为收益与收盘统计基础；
  具体历史接口目前仅列日线，不能据此承诺分时回踩回测。
- [指数目录与行情](https://fuyao.aicubes.cn/docs/api-reference/a-share-index/)：可查询候选指数；
  四项指标的真实代码、覆盖和编制口径仍待有权限的检索及对账。
- [涨跌停和炸板池](https://fuyao.aicubes.cn/docs/api-reference/limit-up-data/)：可用于样本及情绪统计；
  必须取尽分页，连板天梯截断数据不能代替完整样本。
- [集合竞价](https://fuyao.aicubes.cn/docs/api-reference/auction/)：可作为开盘前独立更新的辅助，
  不替代盘中逐笔成交，也不能进入 08:50 基线。
- [主力资金](https://fuyao.aicubes.cn/docs/api-reference/capital-flow/)：文档明确暂未开放外部接入，
  大小单分类阈值和原始订单/成交拆分口径也需要供应商确认。
- [高频动向](https://fuyao.aicubes.cn/docs/api-reference/high-frequency/)：暂未开放外部接入；
  返回的是高频动向指标，不能等同于原始分钟 OHLC 或逐笔委托。
- 主动买卖成交、盘口挂单、完整分钟或逐笔行情：尚未确认 Fuyao 可调用接口，需另核数据源。

“买单大于卖单”必须明确是主动成交金额、成交笔数还是盘口委托量。
一笔成交同时有买卖双方，所谓净流入依赖分类算法，不能直接解释为真实机构持仓增加。
盘口委托可能撤单，与已经成交的主动买卖指标应分开保存和评估。

## 5. 验证顺序

先用已有约 50 笔交易建立最小记录集：买入时间、模式标签、板块、四项表现及其时间、
实际进出价格、费用、持仓时间、净收益和最大不利波动；缺少历史时点数据时明确标缺。
每笔交易关联买入前已知的环境，而不是当天最终收盘环境。

先比较各环境的样本数、胜率、平均盈利/亏损、净期望和亏损尾部；不能只比较胜率。
同一天多笔交易有相关性，需同时查看交易日数，避免把它们当成完全独立证据。
小样本先验证少量预先指定指标，后续按时间留出新样本验证，不反复调阈值后宣称有效。
被过滤而未买入的候选也应记录，才能评估过滤器是否错过机会。

本次仅记录模式与候选指标，没有更改规则、仓位配置或数据接入代码。
