# 第三轮：取消 50% 下限后的权重比较

日期：2026-09-28。状态：本轮实现、历史开发比较和复核完成。
已取消下行稳定性至少 50% 的限制；105 个组合只有三个等权对照通过，102 个非等权组合均未通过。
因此没有发现同时改善本次风险与封板要求的新权重，不把保留等权称为优化成功。

## 一、变更及边界

四项特征仍为下行稳定性、五日趋势、收盘位置、流动性，每项允许 0% 至 100%，步长 25%，
合计 100%。完整网格为 35 组，结合 ALL、ABC、AB 三种环境共 105 个组合。
开放的是权重范围，仍采用有限离散网格，未穷举任意小数权重，也未引入负权重。

同日期、环境及每日数量的已记录封板比例不能低于等权基准，平均下行与尾部下行不能高于基准。
最低样本、事件数及分布要求全部沿用第二版。完整规则见
[第三轮冻结协议](open-weight-study-plan-20260928.md)。

通过来源摘要、原实现摘要和重新计算的配对基准核验后复用第二版 30 组，新计算 75 组。
第一、二版实现及结果均保留，未重建面板、重新下载历史数据或替换正式推荐。

## 二、结果及原因

| 项目 | 数量 |
| --- | ---: |
| 全部权重与环境组合 | 105 |
| 等权对照 | 3 |
| 非等权组合 | 102 |
| 通过全部训练、验证门槛的非等权组合 | 0 |
| 两段封板比例均不低于配对基准的非等权组合 | 50 |
| 上述 50 组中两段平均下行均高于基准 | 50 |

这次扩展确实找到了更多命中达标的组合，但它们全部付出了更高的平均下行代价。
因此，失败并非只是样本事件数不足。其余 52 个非等权组合在训练期封板比例上未达标。

| 非等权组合未通过原因（可重叠） | 训练 / 102 | 验证 / 102 |
| --- | ---: | ---: |
| 封板比例低于配对基准 | 52 | 40 |
| 平均下行高于配对基准 | 60 | 60 |
| 尾部下行高于配对基准 | 49 | 49 |
| 封板事件少于 10 条 | 21 | 18 |
| 封板事件分布不足 5 日 | 13 | 10 |

最终排序保留的是 A/B 环境下四项各 25% 的等权对照，状态为 baseline_retained。
它与自己的配对基准完全一致，验证风险改善为零；不是新的优化权重。

| 等权 A/B 对照指标 | 开发训练 | 开发验证 |
| --- | ---: | ---: |
| 观察日 / 股票日记录 | 78 / 780 | 43 / 430 |
| 已记录封板事件 | 25 / 780，3.205% | 18 / 430，4.186% |
| 平均盘中下行 | 1.980% | 2.170% |
| 尾部盘中下行 | 4.240% | 4.282% |
| 平均盘中上涨空间 | 2.411% | 2.780% |

下行指相对当天开盘的盘中最低价跌幅，尾部为最差 10% 观察日的每日均值再求平均。
上述指标不是账户最大回撤、可成交收益或交易策略胜率。不同环境的排序也不能单独证明环境过滤有效。

## 三、验证范围与限制

- 训练为 2025-09-17 至 2026-03-16，验证为 2026-03-17 至 06-16，均为已经研究过的开发数据。
- 2026-06-17 至 09-16 的第一版旧留出未加载用于本次选择。没有新样本外检验结果。
- 历史资格、完整合法涨停价及池外标签仍未知；命中为已记录事件比例，不是完整真实首板成功率。
- 连续一年池中三条缺失日线、证券范围和历史资格缺口仍按前版处理，不填零或用当前资格回填。
- 没有更改正式推荐；没有启动新采集或新的自动任务。已有续作 automation 保持暂停。
- 结论仅覆盖此四项特征及 25% 步长的网格，不能扩展成“所有可能权重都无效”。

## 五、后续建议

本次解除下限的工作已完成。若继续研究，可先用本轮逐组结果明确命中与风险的取舍，
再预先固定更细网格或新特征的有限研究范围；任何新选择都需要未参与调参的新时间窗口验证。
不能因为本轮没有非等权组合通过，就临时降低已确认的命中或风险要求，或把等权当作已验证上线方案。
