## 二、时间与数据口径

令 T 为观察日，D、P 为其前两个参考交易日：

- 四项环境输入为各指数 `close(D) / close(P) - 1`，不使用 T 日行情决定 T 日权限。
- 观察结果为首板指数 `close(T) / close(D) - 1`，只在事后评价阶段使用。
- 参考日历使用首板指数的完整日期集合，三年 726 日已与同区间沪深 300 返回日期集合对账一致。
- 单日必要价格缺失、非有限、非正或低于研究过滤门槛时，保留明确排除原因；不填零、不插值、不跨缺日算日收益。
- 二板指数缺少 2026-03-05，导致 2026-03-06 与 2026-03-09 的环境输入不完整，排除这两个 T 日。
- 最低指数收盘门槛固定为 1.0，仅是研究质量过滤，不代表供应商保证精度。
  本次近期区间及预热期四指数最低收盘分别为 257.905、15.241、1959.864、57.499，未触发该门槛。

2026-09-15 四项历史收盘计算涨幅，已与此前保存的官方快照逐项对账，误差不超过 0.000001 个百分点。
一次近期对账不能证明三年所有异常值均可靠；早期二板零值和极小价格阶梯没有混入本次近期研究。
详细异常和历史覆盖见 [同花顺核验报告](fuyao-history-coverage-20260918.md)。

历史数据为事后取得，对象中的时间仅是研究用合成观察时点，不代表当时真实采集时间。
仅复用基础环境判断，没有重放新闻、外围风险闸门或仓位规则，也没有接入正式盘前报告。

## 三、实现与验证

- [environmentReplay.py](../../src/quant_forge/research/environmentReplay.py) 的 `replayEnvironment`
  输出逐日环境、排除原因、基础权限和分组统计，保持生产权重配置不变。
- `_returnPct` 按输入价格的十进制表示计算涨幅，避免恰好上涨 2% 因浮点误差升级权限；
  不做固定小数位截断，保留阈值两侧真实差异。
- `_summarize` 对中间样本使用稳健均值计算中位数，避免有限大数求和溢出；
  下十分位按 `(N - 1) × 0.1` 线性插值，空样本输出空值。
- [test_environmentReplay.py](../../tests/test_environmentReplay.py) 共 40 个用例，覆盖因果顺序、
  缺日传播、异常价格、固定评估区间、空样本、分组、阈值精度和数值溢出。
- 按先失败后修复执行阈值与中位数回归测试；全量测试 204 项通过，整体覆盖率 91.14%，
  新回放模块覆盖率 95%；相关文件静态检查通过。

在项目根目录执行：

```text
python outputs/research/environment-replay-20260918/runReplay.py
python -m pytest
```

回放读取 [冻结输入清单](../../outputs/research/environment-replay-20260918/input-manifest.json)，

## 四、与股票权重优化之间的缺口

原有六项权重作用于板块评分，其历史输入包含历史板块成分、广度、涨停数、成交变化、持续性、催化及拥挤度。
现有可访问数据尚未补齐这些输入，不能用当前成分回填历史，也不能用日线价格代理冒充原模型。

盘前首板候选还需要连续完整的昨日涨停与炸板池、历史 ST 和交易状态；
触板及封板标签需要验证当日两个池的收盘语义和覆盖。账户回撤另需买卖、持仓和费用口径。

因此本次保留现有生产权重，不给出未经验证的“最优权重”。下一步需要确定：
补齐原模型历史输入，或另行研究可由已核验日线构造的评分权重，并明确其为新模型。
随后才能冻结数据和标签、按时间划分训练与留出区间、以风险优先比较方案。
